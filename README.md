# unkernel mirror

A GitHub Pages mirror of [unkernel.dev](https://unkernel.dev) — a real Linux kernel
compiled to WebAssembly that boots to a shell in under a second.

Created by Pooya Parsa and the pithings contributors:
<https://github.com/pithings/unkernel>

The upstream project is licensed GPL-2.0 (see the upstream repository for the full
license text). This repository contains no source code: a workflow downloads the
publicly served build from unkernel.dev, rewrites its root-absolute asset paths so it
works under a project Pages URL, and publishes it. All credit belongs upstream.
